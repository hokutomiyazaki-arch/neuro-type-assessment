# 神経タイプ診断 PWA

FNT（Functional Neuro Training）による神経タイプ診断アプリケーションです。

## 概要

質問に答えることで、あなたの神経学的なタイプを分析し、どの神経領域にアプローチすべきかを判定します。

## 診断タイプ

- **レセプタータイプ** - 感覚受容器の問題
- **末梢神経タイプ** - 神経伝達の問題
- **脊髄タイプ** - 中心軸の問題
- **小脳タイプ** - 協調運動の問題
- **脳幹タイプ** - 左右の神経統合の問題
- **視床タイプ** - 感覚統合の問題
- **大脳皮質タイプ** - 運動野・感覚野の問題
- **島皮質タイプ** - 内受容感覚の問題

## 機能

- PWA対応（オフライン動作可能）
- スマートフォン最適化
- ホーム画面へのインストール対応

## 使い方

1. 「診断を開始する」をタップ
2. 各質問に「はい」か「いいえ」で回答
3. 診断結果とアプローチ方法を確認

## 注意事項

この診断は参考情報であり、医学的な診断ではありません。症状がある場合は、必ず専門の医療機関を受診してください。
